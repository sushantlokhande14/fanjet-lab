# Electric Fan-Jet Lab

What if a plane had jet engines with no fuel in them?

Just a battery and fans: a big intake fan, two more fans behind it and a small
nozzle, six engines under a straight wing. Does it fly, and how far?

Starting with the engine. Each fan is a mean-line stage with its own motor, the
swirl it leaves carries on to the next fan, and the solver finds the mass flow
the nozzle will pass.
